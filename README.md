# Multi-Tenant CRM SaaS

This repository contains the foundation for a multi-tenant CRM SaaS application.

## Directory Structure
- `frontend/` - Next.js TypeScript application
- `backend/` - FastAPI Python application
- `docs/` - Architecture and engineering documentation

## Getting Started
See the individual README files in `frontend/` and `backend/` for setup instructions.
For local infrastructure, run:
```bash
docker-compose up -d
```
